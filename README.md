# 💊 حاسبة الجرعات الدوائية (Dosage Calculator)

أداة ويب تعليمية مبسطة مصممة خصيصاً لطلاب الصيدلة، تتيح حساب الجرعات الدوائية الدقيقة بناءً على وزن المريض والتركيز الموصى به.

## ✨ المميزات (Features)

- **حساب الجرعة:** حساب الجرعة المطلوبة لكل مرة (Per Dose) أو الجرعة اليومية الإجمالية (Per Day).
- **تحويل الوحدات:** دعم وحدات قياس متعددة للجرعة (مجم، ميكروجرام، جم).
- **حساب الحجم:** حساب حجم الدواء المطلوب بالسنتيمتر المكعب (مل) بناءً على تركيز الدواء المتوفر.
- **دعم التركيزات المختلفة:** يدعم التركيزات بوحدات (مجم/مل، جم/مل، مجم/5مل).
- **واجهة عصرية:** تصميم متجاوب (Responsive) وسريع يعمل على جميع الشاشات (جوال، تابلت، كمبيوتر) مع دعم كامل للغة العربية (RTL).

## 🚀 كيفية التشغيل محلياً (How to Run Locally)

لا تحتاج إلى أي أدوات بناء معقدة أو خوادم. المشروع مبني بتقنيات الويب الأساسية:
1. قم بتحميل أو نسخ المستودع (Clone).
2. افتح ملف `index.html` في أي متصفح ويب حديث.
3. ابدأ بإدخال البيانات لحساب الجرعة.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **HTML5** - لهيكلة الصفحة.
- **CSS3** - للتصميم والواجهة المتجاوبة (بدون استخدام أطر عمل خارجية لضمان السرعة).
